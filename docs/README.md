# automato-core-py documentation

[Back to the project](../README.md)

The core defines the model shared by every Automato component. These pages are the reference for definitions and for the MQTT protocol; the node and the clients link here.

1. [Concepts](concepts.md): entries, nodes, clients, events, actions, metadata
2. [Entry definitions](entry-definition.md): keys of a definition, publish and subscribe rules, topic rules
3. [Events and actions](events-and-actions.md): declaring and listening to events, references, calling actions, standard event names
4. [Scripting](scripting.md): `js:` and `jsf:` expressions, variables and helper functions
5. [Notifications](notifications.md): texts and levels of messages
6. [MQTT protocol](mqtt-protocol.md): payloads, metadata, data and notification topics
7. [Python API](python-api.md): using the core from Python

Other projects:

- [automato-node-py documentation](https://github.com/eric-void/automato-node-py/blob/master/docs/README.md): running a node, configuration, modules
- [automato-core-js](https://github.com/eric-void/automato-core-js): the JavaScript core
- [automato-http-client](https://github.com/eric-void/automato-http-client): the web client
